Project Overview

FakeGuard AI is an end-to-end deep learning system that classifies news articles and headlines as FAKE or REAL using four different neural architectures. The project compares RNN, CNN, BERT, and GNN — with the Graph Neural Network achieving the highest accuracy of 94.8% by modelling word relationships as a graph rather than a sequence.

Deep Learning Models

RNN — Recurrent Neural Network 82.3%
  • Architecture: Bidirectional LSTM
  • 2 layers, 256 hidden units, dropout 0.3
  • Global max pooling over time steps
  • Best for: sequential pattern capture
CNN — Convolutional Neural Network 85.7%
  • Architecture: TextCNN
  • Parallel convolutions: kernel sizes 2, 3, 4
  • 128 filters per kernel, max-over-time pooling
  • Best for: local n-gram feature extraction
BERT — Transformer Language Model 91.2%
  • Architecture: bert-base-uncased (fine-tuned)
  • 110M parameters, 12 attention heads
  • [CLS] token → dropout → linear classifier
  • Best for: contextual language understanding
GNN — Graph Neural Network ★ BEST 94.8%
  • Architecture: 2-layer Graph Convolutional Network
  • Word co-occurrence graph (window size 3)
  • Symmetric normalised adjacency + self-loops
  • Global mean pooling over node embeddings
  • Best for: relational / structural text patterns
